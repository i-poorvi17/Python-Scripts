# Python-Scripts 🐍

A collection of beginner-friendly Python scripts written while practicing core programming concepts — logic building, 
string manipulation, recursion, and small utility tools. Great starting point for anyone learning Python fundamentals.

## 📂 Scripts Overview

| Script | Description |
|---|---|
| `greet.py` | Simple greeting program |
| `calc.py` | Basic calculator (functions-based) |
| `calc_class.py` | Calculator implemented using OOP (classes) |
| `fact.py` | Factorial of a number |
| `fibo.py` | Fibonacci series (iterative) |
| `fibor.py` | Fibonacci series (recursive) |
| `prime.py` | Check whether a number is prime |
| `armstr.py` | Check for Armstrong numbers |
| `pali.py` | Palindrome checker |
| `revnum.py` | Reverse a given number |
| `leap.py` | Leap year checker |
| `gcd,lcm.py` | Find GCD and LCM of two numbers |
| `countvow.py` | Count vowels in a string |
| `ana.py` | Anagram checker |
| `gst.py` | GST calculation |
| `calendar.py` | Print calendar for a given month/year |
| `passgen.py` | Random password generator |
| `qrmaker.py` | QR code generator |
| `translate.py` | Text translator |
| `search_in_file.py` | Search for a keyword inside a file |
| `kbc.py` | Kaun Banega Crorepati style quiz game |
| `snakewatergame.py` | Snake-Water-Gun game |


## 🎯 Purpose

This repo documents my early Python practice — fundamentals every Python developer should try at least once before moving to advanced projects. It also serves as a quick reference for common logic-building problems (recursion, string ops, number theory).

## 🛠️ Tech Stack

- Python 3.x

## 📌 Note

Some scripts (like `passgen.py` and `qrmaker.py`) may need extra libraries — install them via:

```bash
pip install qrcode
```
